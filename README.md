# Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with React Native and TypeScript. The app uses React Navigation to move between the player setup screen and the game board.

## Features

- Enter names for both players.
- Play on a 3 × 3 board, taking turns as X and O.
- Detects a winner across rows, columns, and diagonals.

## Built With

- React Native
- TypeScript
- Expo
- React Navigation

## Requirements

- Node.js and npm
- Expo Go on an Android or iOS device, or an Android emulator

## Run the App

Open a terminal in the project folder and install the dependencies:
